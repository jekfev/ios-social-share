# Changelog

## 1.3 — 2026-09-24

- Добавлены уникальные счетчики нажатий.
- Для каждого поста и каждой сети учитывается только один уникальный посетитель.
- Для авторизованных пользователей используется WordPress user ID.
- Для анонимных посетителей используется случайный cookie-ID.
- Добавлены отдельные таблицы для счетчиков и уникальных событий.
- Добавлена защита от повторного увеличения счетчика на уровне базы данных.
- Добавлен rate limit для AJAX-запросов.
- IP-адреса не сохраняются в открытом виде: используется HMAC-хеш.
- Все иконки перенесены внутрь плагина.
- Убраны внешние CDN для иконок.
- Размер кнопок установлен 50×50 px.
- MAX использует отдельный локальный белый логотип поверх градиентного фона.
- Добавлена поддержка PHP-функции `ios_social_share()` и shortcode `[ios_social_share]`.

## 1.2

- Локальные SVG-иконки.
- Отдельный фон и белый логотип MAX.
- Кнопки 50×50 px.

## 1.1

- Добавлена PHP-функция `ios_social_share()`.
- Добавлена поддержка вызова из WordPress-шаблона.

## 1.0

- Первая версия кнопок VK, Telegram, MAX, Одноклассники и WhatsApp.
- Стиль иконок приложений iPhone.
- Красный счетчик нажатий.
